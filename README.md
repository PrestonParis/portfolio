# Preston Paris — Software Portfolio

An interactive systems portfolio for Preston Paris, a Georgia State University computer science student graduating in May 2027. The site presents each project through live previews, architecture diagrams, state flows, runtime traces, and code paths instead of a conventional gallery.

## Featured projects

- [**WebWidgets**](https://webwidgets.me) — a customizable personal workspace built with Next.js, Supabase, FastAPI, and durable background jobs. [Source](https://github.com/PrestonParis/aidash)
- [**EveryChurch**](https://everychurch.co) — a searchable church directory and community platform with verified submissions and an automated data pipeline. [Source](https://github.com/PrestonParis/everychurch)
- [**Worldview**](https://github.com/PrestonParis/worldview) — political research and visualization across public officials, legislation, money, elections, and geography.

Secondary tiles show ongoing work in computational geometry and geographic visualization. Each project inspector links directly to its repository and, where available, its live deployment.

## Built with

- Next.js 16 and React 19
- TypeScript and Tailwind CSS
- React Three Fiber and Three.js
- Framer Motion, D3, Shiki, and Zustand

## Running locally

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Verification

```bash
npm run check
npm run build
```

## Deployment

The application is ready for a standard Next.js deployment. A public portfolio URL or custom domain still needs to be selected before adding the link to application materials.
